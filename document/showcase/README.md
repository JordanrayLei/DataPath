# DataPath 项目作品集

这里集中展示 DataPath 的产品方案、核心能力、关键设计与测评结果。

如果第一次了解项目，建议先看完整介绍 PPT，再根据关注点进入 Case Study、PRD、测评方法或产品决策。

## 快速了解

### 项目全貌

[下载 AI 产品经理作品集](DataPath-AI产品经理作品集.pptx)

PPT 通过真实运行界面、DDL 验收证据和产品交互稿，完整介绍：

- 数据接入与业务域治理；
- 指标中心、AI 语义预热和 Join Graph；
- 问数工作台、DSL、Evidence 与权限门禁；
- Schema 影响传播；
- Bad Case、Golden 回归和测评监控；
- 产品特点、项目资产与当前结果。

### 产品方案

在 PPT 之后阅读[产品 Case Study](01-product-case-study.md)。

Case Study 解释项目为什么选择可信 ChatBI 方向、目标如何定义、方案怎样组成、做过哪些关键取舍，以及当前项目已经完成到什么程度。

### 专题设计

依次阅读：

1. [Bad Case 自助闭环 PRD](02-badcase-closure-prd.md)；
2. [指标体系与测评方法](03-metrics-and-evaluation.md)；
3. [核心产品决策记录](04-product-decisions.md)。

这三份文档分别展开质量闭环、测评体系和关键产品取舍。
