# DataPath 产品路线图

> 更新日期：2026-07-13
> 类型：目标导向，不承诺具体发布日期

## 当前已完成：可信多表 MVP

- Olist 九表数据加载、校验和快照管理。
- 12 个治理指标与 5 条已发布安全 Join Path。
- Query Understanding、Hybrid Retrieval、歧义门禁和边界拒绝。
- Query DSL 2.0、Semantic Join Graph、Deterministic Planner 和 SQL Compiler。
- 多轮会话上下文与显式条件覆盖。
- 表格、图表、Profiler、Evidence、Interpretation 和 Reflection。
- 指标草稿/发布与 Join 关系草稿/验证/发布。
- Bad Case、黄金问题、360 条黄金集和 80 条发布回归。
- 百炼 `text-embedding-v3`、pgvector 与 `qwen3-rerank`。

## V1.1：质量门禁统一

**目标：** 将当前 91.25% 发布回归提升到可稳定发布的质量水平。

| 事项 | 优先级 | 完成出口 |
| --- | --- | --- |
| 统一 CLARIFY / REJECT / BLOCKED | P0 | 7 条开放回归 Bad Case 关闭 |
| 状态分类前置安全意图识别 | P0 | DDL、DML、敏感导出稳定 BLOCKED |
| 歧义问题候选策略 | P0 | 无指标但有分析意图时稳定澄清或明确拒绝 |
| 检索阈值校准 | P1 | 按黄金集分布校准，不以固定分数冒充概率 |
| 评测报告版本化 | P1 | 报告关联代码、指标、模型和数据快照 |

## V1.2：指标治理闭环

**目标：** 从“可创建发布”升级为“可协作治理”。

- 提交、审核、驳回、撤回、废弃和重新启用。
- 版本差异、回滚指引和生效时间。
- 指标变更影响的黄金问题、历史查询和下游模型分析。
- Owner、审核人、SLA 和通知机制。

## V1.3：数据源与元数据同步

**目标：** 允许接入用户自有数据源并降低语义模型维护成本。

- PostgreSQL/MySQL/ClickHouse 连接配置和只读凭证。
- Schema 扫描、字段采样、类型映射和数据预览。
- 定时对比 Schema 快照，识别表/字段新增、删除和变更。
- 自动生成模型与 Join Relation 候选，由负责人审核发布。
- 数据源、模型和关系变更通知。

## V1.4：Aggregate-Before-Join

**目标：** 安全支持支付、评价等多事实分析。

- 在各事实表先按目标粒度聚合，再执行 Join。
- 对多对多、覆盖率不足和重复键路径默认阻断。
- 为支付金额、支付方式、评价分数等新指标增加独立 Oracle。
- 压测 HNSW、Join Planner 和 ClickHouse 查询成本。

## 企业化阶段

仅在获得真实试点后启动：组织与工作空间、SSO、RBAC、行列权限、敏感字段脱敏、多租户隔离、密钥管理、限流、监控告警、审计、备份恢复、私有化部署和 SLA。

## 暂不优先

- 多 Agent 自治分析。
- MCP 大规模工具生态。
- 跨会话长期用户画像记忆。
- 自动数据写回或业务动作执行。
- 缺少实验与业务上下文时的自动因果归因。
