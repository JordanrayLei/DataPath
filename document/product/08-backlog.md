# DataPath 需求池与迭代管理

> 优先级方法：用户价值、可信风险、战略匹配、实现成本和前置依赖综合评估

## 1. 需求状态

`DISCOVERY → READY → IN_PROGRESS → VALIDATING → DONE`  
无法证明价值或依赖未满足的需求保持 `DISCOVERY`，不得直接进入开发。

## 3. 下一迭代建议

迭代目标：完成指标治理最小闭环，并为真实数据源接入建立稳定元数据基础。

建议范围：`MET-01`、`MET-02`、`MET-03`、`AI-01`。数据源接入先完成技术方案与用户流程设计，不与指标治理同时扩大开发范围。

## 4. Definition of Ready

- 用户和问题明确。
- 当前替代流程已说明。
- 范围、非范围和异常状态明确。
- 数据、权限和AI风险已评估。
- 有可执行验收标准和评测样本。
- 前置依赖已完成或进入同一迭代。

## 5. Definition of Done

- 用户主流程与异常流程可运行。
- 接口、数据模型和页面状态一致。
- 自动测试与相关黄金问题通过。
- 埋点或运行指标可观测。
- PRD、路线图和版本记录同步更新。
- 已实现与规划状态在对外材料中一致。
